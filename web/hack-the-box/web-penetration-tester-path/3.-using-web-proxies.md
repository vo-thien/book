## proxychains

Giúp chuyển toàn bộ traffic của tool đi qua proxy được chỉ định (Burp Suite). Không nhất thiết tool đó phải hỗ trợ proxy.

{% code overflow="wrap" lineNumbers="true" expandable="true" %}
```bash
sudo apt update
sudo apt install --reinstall proxychains4 -y
sudo nano /etc/proxychains4.conf
```
{% endcode %}

Chỉnh sửa file config:

* Comment socks4 bằng dấu #
* Thêm dòng **`http 127.0.0.1 8080`** (Khoảng cách giữa chúng là phím Tab)

<figure><img src="../../../.gitbook/assets/image (87).png" alt=""><figcaption></figcaption></figure>

Sau đó sử dụng lệnh

{% code overflow="wrap" lineNumbers="true" expandable="true" %}
```bash
proxychains4 -q -f /etc/proxychains4.conf curl https://webhook.site/09928754-fc91-41fa-a182-1ecfd80dc293

-q: quiet - ít hiển thị log
-f: Chỉ định file config
```
{% endcode %}

<figure><img src="../../../.gitbook/assets/image (88).png" alt=""><figcaption></figcaption></figure>



## Metasploit

Cũng có thể set được proxy

{% code overflow="wrap" lineNumbers="true" expandable="true" %}
```
set PROXIES HTTP:127.0.0.1:8080
```
{% endcode %}

<figure><img src="../../../.gitbook/assets/image (89).png" alt=""><figcaption></figcaption></figure>

Ngoài ra có thể set global cho mọi module trong phiên làm việc hiện tại bằng lệnh

{% code overflow="wrap" lineNumbers="true" expandable="true" %}
```
setg PROXIES HTTP:127.0.0.1:8080
```
{% endcode %}
